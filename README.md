# Los Roques

Cayo de Agua, in the Los Roques archipelago of Venezuela: a real place to stand in, in your browser.

**[Open it](https://lelelilo-studios.github.io/los-roques-web/)**

It is drawn with WebGPU, so it needs a browser that has it: Chrome or Edge on Windows, macOS and ChromeOS, Chrome on
Android 12 and later, Safari on iPhone, iPad and Mac (iOS, iPadOS and macOS 26), and Firefox on Windows. Where WebGPU
is missing, the page says so instead.

This repository holds only the built site. The credits for the map data are in the page.
